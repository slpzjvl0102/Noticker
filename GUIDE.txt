Noticker 시작 가이드
====================

Noticker는 Windows 바탕화면에 스티커 메모를 붙이고 Notion DB와 자동으로 동기화하는 앱입니다.


[ 시스템 요구사항 ]

- Windows 10 64비트 이상
- 인터넷 연결 (Notion 동기화 시)


[ 설치 ]

Noticker.exe를 원하는 위치에 놓고 실행하세요.
설치 과정은 없습니다.


[ 처음 실행 시 설정 ]

앱을 실행하면 시스템 트레이(우측 하단 시계 옆)에 아이콘이 생기고
설정 창이 자동으로 열립니다.

설정에 필요한 두 가지:

  1. Notion API Token
     - https://www.notion.so/my-integrations 접속
     - "새 API 통합" 클릭 → 이름 입력 → 제출
     - 표시된 "내부 통합 토큰" 복사 (secret_... 로 시작)

  2. Notion Database ID
     - 메모를 저장할 Notion 데이터베이스 페이지 열기
     - 우측 상단 "..." → "연결" → 위에서 만든 통합 추가 (이 단계 필수!)
     - 주소창 URL 복사 (예: https://www.notion.so/워크스페이스/제목-32자리코드?v=...)
     - URL 전체를 Database ID 칸에 붙여넣기하면 자동으로 추출됩니다

두 값 입력 후 "연결 테스트" 버튼으로 확인 → "저장"


[ 카테고리 색상 사용하기 ]

Notion DB에 Select 타입 속성이 있으면 카테고리별로 스티커 색상이 바뀝니다.

  1. 설정 → "CATEGORY PROPERTY 이름"에 Notion의 속성 이름 입력 (기본값: Category)
  2. "옵션 새로고침" 클릭
  3. 스티커 하단에서 카테고리 선택 → 바 색상이 Notion 색상과 동기화됩니다


[ 기본 사용법 ]

  - 트레이 아이콘 좌클릭   : 새 스티커 생성
  - 트레이 아이콘 우클릭   : 메뉴 (설정 / 종료)
  - 스티커 상단 바 드래그  : 이동
  - 스티커 우하단 핸들     : 크기 조절
  - 스티커 × 버튼         : 삭제 (Notion 내용은 유지됨)


[ 동기화 상태 표시 ]

스티커 좌상단의 작은 점으로 확인합니다.

  ● 초록  : Notion에 동기화 완료
  ● 노랑  : 동기화 대기 중 (입력 후 약 1.5초 뒤 자동 전송)
  ● 빨강  : 동기화 실패 (토큰/DB 설정 확인 필요)


[ 자주 묻는 것들 ]

Q. 앱을 껐다 켜도 스티커가 남아있나요?
A. 네. 모든 메모는 로컬에 저장되어 재시작해도 그대로 복원됩니다.

Q. Notion에서 직접 수정한 내용이 스티커에 반영되나요?
A. 아니요. 현재는 스티커 → Notion 단방향 동기화입니다.

Q. 여러 모니터를 사용하는데 위치가 기억되나요?
A. 네. 모니터별로 위치가 저장됩니다.

Q. 데이터는 어디에 저장되나요?
A. C:\Users\사용자이름\AppData\Roaming\Noticker\noticker.db
